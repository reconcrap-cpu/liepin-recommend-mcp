## Learnings
- 当前 `有简历` filter 下仍然同时存在：
  - `索要简历`
  - `索要中`
  - `看简历`
  - `UNKNOWN`
  - system rows
- 因此状态按钮/row type 是 chat screening 的真实 gate，filter 标签不能作为筛选依据。
- `索要简历` 是唯一会进入 LLM 的状态；这与用户要求一致。

## Pitfalls
- 不能因为 row 在 `有简历` filter 下就调用 LLM。
- system row 即使出现 `浏览简历` 文本也必须跳过。
- `UNKNOWN` 需要安全跳过，不能猜测为 screenable。
