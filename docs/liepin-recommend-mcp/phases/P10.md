## Learnings
- P10 不需要重新触发网页交互；P07 已经生成足够的 live 样本池。
- Parser 对 P07 的 19 个结构签名都有至少 1 份覆盖，实际覆盖为 60 份样本全量通过。
- Parser 会比 P07 taxonomy 捕获更多底部 section，例如 `recruit_records` 和 `resume_notes`；这是覆盖提升，不是与采样记录冲突。

## Pitfalls
- “section 覆盖一致”不能理解为 parser 只能输出 taxonomy 中的 section；更安全的定义是 parser 至少覆盖采样记录中的 expected sections，同时允许捕获额外尾部 section。
- 后续 P11 做 LLM payload 时必须使用 parser 的 `orderedSections`，否则容易漏掉 `recruit_records`、`resume_notes` 等尾部内容。
