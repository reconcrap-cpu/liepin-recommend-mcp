## Learnings
- P22 的 chat 子流程可以把 `recommend_basic_chat_modal` 投影成 P14/P16 的 chat row state：
  - `索要简历` -> screenable，允许 chat LLM。
  - `索要中`、`看简历`、`浏览简历`、未知状态 -> skip，不调用 chat LLM。
- 同页基础聊天 modal 没有传统聊天列表 row；P22 使用候选人姓名、简历编号、header、消息区、action bar 构建 `liepin_chat_screen_input_v1`。
- `request_resume` 默认保持 dry-run；真实点击由 `--execute-request-resume` 单独控制。

## Pitfalls
- 不要把 recommend LLM 的 `pass/chat` 直接等同于索要简历；必须先进入同页 chat modal，并重新按 chat action state 判定。
- 不要从 `索要中`、`看简历`、`浏览简历` 或未知状态点击索要简历。
- 不要把跳转到 `/chat/im` 当成 P22 通过；P22 目标入口是 P21 验证过的同页 `recommend_basic_chat_modal`。
- 实机 P22 会产生真实沟通副作用，运行前需确认授权和风控状态。
