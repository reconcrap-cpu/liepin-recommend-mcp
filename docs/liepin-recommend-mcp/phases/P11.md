## Learnings
- “LLM 看完整 CV”的 v1 验证可以通过输入 manifest 完成，不需要要求模型输出 pass/fail reasons。
- `profile` 也需要作为 payload section 进入 manifest，否则候选人顶部摘要会在 section-only payload 中丢失。
- `payloadSectionIds` 可以包含 `profile`，而 `parsedPresentSectionIds` 只包含 CV section；audit 只要求 parsed CV sections 都被 payload 包含。
- `maxPayloadChars` 只用于测试截断保护；生产默认不截断。

## Pitfalls
- section 顺序必须使用 parser 的 `orderedSections`，不能按固定 section id 重新排序，否则会改变原始 CV 阅读顺序。
- 重复 section chunk 需要保留，例如 recommend modal 的重复 `推荐职位`。
- P11 只构建和审计输入，不调用 LLM，也不生成 decision。

## Next Phase Notes
