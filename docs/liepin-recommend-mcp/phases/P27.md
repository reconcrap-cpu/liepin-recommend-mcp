## Learnings
- 推荐沟通入口在 live 环境里并不稳定绑定到同一种 UI；同页 basic chat modal 与 `/chat/im` 都需要被当作有效入口处理。
- 当浏览器里同时开着旧 chat 页和新跳转出来的 chat 页时，不能靠“第一个 chat target”做判断，必须 target-aware。
- “async start” 这种 operator surface 不能只在语义上 async；如果 worker 没有真正后台化，实机里一跑就会露馅。

## Pitfalls
- P27 会产生真实沟通和真实索要简历副作用；没有明确授权时不能复用这组命令。
- 历史 run 不会被回填成 P27 的更好 artifacts；新的 candidateLabel 优先级只对后续 run 生效。
- 不要把 `samePageChatEntries=0` 直接视为失败；真实环境可能改走 `chat_page`，要看支持的 entry kind 总量和后续 screening/action 是否完成。
