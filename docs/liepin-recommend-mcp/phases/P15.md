## Learnings
- `索要简历` 点击后会出现二次确认弹窗，文案为 `确定向对方索要简历吗？`。
- 确认按钮 DOM 文本渲染为 `确 定`，必须去掉空白后按 `确定` 匹配。
- 确认接口为：
  - `https://api-lpt.liepin.com/api/com.liepin.im.b.askfor.send-askfor-request`
- 成功后 action bar 从 `索要简历` 变为 `索要中`，聊天消息中出现 `我想要一份你的简历，你是否同意？`。
- 请求成功后会话列表可能因为新消息重排，后续状态验证必须使用 `rowKey`，不能使用原始 row index。

## Pitfalls
- 不能点包含 `取 消确 定` 的容器；必须点 modal 内真实 `button`。
- CDP 坐标点击在本页面未稳定触发确认业务逻辑；实测 `button.click()` 对真实确认按钮可触发接口。
- 早期实现用 row index 验证状态，列表重排后误把另一个候选人的 `索要中` 当成成功；已改为同 `rowKey` 验证。
- Ant modal 可能留下动画残影；动作执行器现在会在确认残留时刷新 chat 页清理。
