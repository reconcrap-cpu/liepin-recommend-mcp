# P03

## Goal
Implement the async run ledger and fixed run artifact layout without depending on later business logic.

## Actual Changes
- Added `src/run-state.js`.
- Standardized per-run artifacts:
  - `run.json`
  - `events.ndjson`
  - `screen-input.json`
  - `llm-request.json`
  - `decision.json`
  - `coverage.json`
  - `reasoning.log`
- Added pause/cancel/resume state mutations and basic worker integration.

## Live Validation Evidence
- Run snapshots are now created before any browser work starts, so failed phases still leave inspectable artifacts.

## Tests
- Added `src/run-state.test.js` to verify run creation, event file creation, pause request, and completion persistence.

## Learnings
- A per-run directory is a better fit than a flat file ledger because we will store screenshots, DOM snapshots, and coverage artifacts later.

## Pitfalls
- Resume support is currently "re-run worker with same run id"; later long-running phases need checkpoint-aware resume semantics.

## Next Phase Notes
- `P04` can now write discovery failures and browser diagnostics into stable run artifacts and doctor output.
