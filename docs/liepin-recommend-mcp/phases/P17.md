## Learnings
- 推荐页筛选入口是顶部 `筛选` 按钮，点击后打开右侧 Ant drawer。
- Drawer selectors：
  - root: `.ant-lpt-drawer-open`
  - body: `.ant-lpt-drawer-body`
  - group: `.filterItems--XYlh8`
  - title: `.itemTitle--y3zfr`
  - tag option: `.ant-lpt-tag-checkable`
  - active state class: `ant-lpt-tag-checkable-checked`
  - reset button text: `重置`
  - apply button text: `确定`
  - close selector: `.ant-lpt-drawer-close`
- `薪资范围（单选）` 在不同渲染状态下标题可能被读成 `薪资范围`，后续实现需要 title prefix 容错。
- 年龄是两个 input，placeholder 分别为 `最低` / `最高`。

## Pitfalls
- 推荐详情 modal 关闭后可能留下 `leave` 动画残影；P17 开始前通过清理 `#preview` 并刷新页面恢复干净推荐页。
- P17 不点击 `确定`，只验证 drawer 内部设置/清空/激活态；筛选实际生效留给 P18。
- `薪资范围 -> 自定义` 会引入额外输入流程，当前没有完成实机验证，不能进入 v1。
- 对 filter group 不能只做 exact title match；薪资标题存在 `薪资范围` / `薪资范围（单选）` 的读法差异。
