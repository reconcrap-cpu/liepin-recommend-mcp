# P01

## Goal
Create the package skeleton, CLI entrypoint, MCP server entrypoint, and the fixed Liepin-prefixed tool names.

## Actual Changes
- Added `package.json`, `bin/liepin-recommend-mcp.js`, `src/index.js`, `src/cli.js`, and `src/json-rpc.js`.
- Reserved the fixed tool names:
  - `liepin_doctor`
  - `liepin_recommend_start`
  - `liepin_chat_start`
  - `liepin_recommend_chat_start`
  - `liepin_run_status`
  - `liepin_run_pause`
  - `liepin_run_resume`
  - `liepin_run_cancel`
- Added research CLI commands needed to complete research-gated early phases without blocking later public interfaces.

## Live Validation Evidence
- CLI and MCP code paths were scaffolded directly in the repo and are ready for smoke testing once dependencies are installed.

## Tests
- Added `src/json-rpc.test.js` to assert `tools/list` exposes `liepin_doctor`.

## Learnings
- Reserving the public interface early keeps later phases from inventing incompatible command names.

## Pitfalls
- The public `start` commands are intentionally mapped to research-stage workers for now; later phases must replace that behavior without renaming the commands.
