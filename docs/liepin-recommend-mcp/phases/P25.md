## Learnings
- The real provider was reachable, but did not initially obey the enum contract. Production code needs both stronger prompting and strict output validation with bounded schema repair.
- `--mock-llm false` was a real CLI footgun because plain string flags were treated as truthy. P25 fixes this for start/research commands.
- Recommend modal DOM can update harmless dynamic text during LLM latency. Dry-run safety should verify stable candidate identity rather than full DOM hash equality.
- Button close can fail even when clicked; reload/navigation fallback is required to return the operator page to a clean recommend list.

## Pitfalls
- Do not log or paste `screening-config.json` apiKey.
- Chat-page real e2e was not run in P25 because no chat page was open in Chrome 9222. The chat provider contract was validated with real LLM synthetic input only.
- `recommend_chat_chain` still requires `--allow-chat-action`; P25 did not run a real chat side effect.
- `request_resume` remains gated by `--allow-request-resume` and was not executed.
