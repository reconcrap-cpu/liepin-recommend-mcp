# P02

## Goal
Implement config resolution and runtime directory initialization under `~/.liepin-recommend-mcp/`.

## Actual Changes
- Added `src/config.js` and `config/screening-config.example.json`.
- Standardized runtime directories:
  - `~/.liepin-recommend-mcp/`
  - `~/.liepin-recommend-mcp/runs`
  - `~/.liepin-recommend-mcp/logs`
  - `~/.liepin-recommend-mcp/research`
- Added screening-config validation for `baseUrl`, `apiKey`, and `model`.

## Live Validation Evidence
- Runtime layout is created eagerly from CLI startup, so subsequent phases can rely on stable paths.

## Tests
- Added `src/config.test.js` covering placeholder rejection and valid config acceptance.

## Learnings
- Keeping the user config in the home runtime rather than the workspace makes multi-instance continuation simpler.

## Pitfalls
- Placeholder API keys must be treated as invalid, otherwise later doctor checks will falsely pass.

## Next Phase Notes
- `P03` should store every run in its own directory so artifacts and phase evidence stay grouped.
